pisces-ai-oauth

Privacy Policy

Overview

pisces-ai-oauth is an open-source OAuth 2.0 utility library for Google Agent Platform (formerly Vertex AI). This website is a static informational page for the library.

Data Collection

This website collects no personal data: no analytics, no cookies, no tracking, and no server-side logging under our control. The library itself runs entirely in the user's own environment.

OAuth Tokens

When the library is used, Google OAuth tokens are stored only on the user's side: in the browser's localStorage (browser build) or in the user's own PostgreSQL database (server build). Tokens are never transmitted to, or stored on, any server operated by this project.

Google Sign-In

Authentication is performed directly between the user and Google via Google Identity Services. Google's handling of data is governed by Google's Privacy Policy.

Third-Party Hosting

This site is hosted on Vercel; Vercel may collect standard access logs per its own privacy policy.

Open Source

Source code is publicly available at github.com/shittim-plana/vertex-ai-oauth.
